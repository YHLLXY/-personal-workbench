# 定时提醒通知 · 上线指引（用户操作）

> 代码已全部部署（Vercel 自动）。完成以下 3 步即可验收。

## 1. Supabase SQL（SQL Editor 执行）

- 表与列：执行 `supabase/migrations/003_reminders.sql`（可重复执行）
- 定时任务（每 10 分钟触发检查；<CRON_SECRET> 替换为第 2 步的值）：

```sql
select cron.schedule('reminder-check', '*/10 * * * *', $$
  select net.http_post(
    url := 'https://personal-workbench-lilac.vercel.app/api/cron-notify',
    headers := jsonb_build_object(
      'authorization', 'Bearer <CRON_SECRET>',
      'content-type', 'application/json'
    )
  ) $$);
```

## 2. Vercel 环境变量（Settings → Environment Variables → 添加 4 个 → Redeploy）

| 变量 | 说明 |
|---|---|
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase 项目设置 → API → service_role key（服务端 cron 用，勿泄露） |
| `CRON_SECRET` | 任意长随机串（cron 鉴权），与第 1 步 SQL 中的值一致 |
| `VITE_VAPID_PUBLIC_KEY` | 推送公钥（见下） |
| `VAPID_PRIVATE_KEY` | 推送私钥（服务端专用，勿泄露） |

生成密钥对（本地执行一次，公钥填入 VITE_VAPID_PUBLIC_KEY、私钥填入 VAPID_PRIVATE_KEY）：

```bash
npx web-push generate-vapid-keys
```

配置后 Redeploy 让 env 生效。
