# 今日概览弹窗 设计文档

> 状态：已批准（2026-08-08）
> 范围：个人工作台（React 19 + Vite + TS + Tailwind v4 + shadcn/ui + Supabase + Vercel）

## 一、需求（用户原话提炼）

不要后台推送，改为：**每次打开应用时弹出一个弹窗**，显示：
1. 今日待办事项的完成情况（进度 + 未完成列表，可勾选直接完成）
2. 考试信息（最近 3 场：名称 + 日期 + 剩余天数；无考试不显示）
3. 更新日志（最近一次更新内容 + 可展开全部历史）

## 二、交互规则

- **触发**：进入首页（home.tsx）挂载 DailySummary → 数据加载完成 → 若「今日有未完成任务 **或** 有未来考试」→ 弹窗；两者皆空 → 不弹
- **频率**：`sessionStorage` 标记 `wb:daily-summary-shown`——**每次打开应用（新会话）弹一次；刷新页面不重复弹**
- **勾选完成**：未完成列表行内 Checkbox，点击调 `updateTask(id, { status: 'done' })`（现有乐观更新）
- 弹窗可关闭（右上角 X / 点击遮罩）

## 三、弹窗内容结构

```
┌─────────────────────────────────┐
│  👋 早上好/下午好/晚上好，今天是 8 月 8 日 │
│                                 │
│  📋 今日待办                     │
│  ▓▓▓▓▓░░░ 已完成 2/5            │  ← Progress 进度条
│  ☐ 写实验报告        14:00      │  ← 未完成任务（含焦点），显示 dueTime
│                                 │
│  📝 考试倒计时                   │  ← 无考试整块不显示
│  高数期末  8 月 11 日 · 3 天后    │  ← 剩余天数：0=今天 / 1=明天 / n=「n 天后」
│                                 │
│  🆕 更新日志                     │
│  v1.4 · 2026-08-08 · 定时提醒通知 │  ← CHANGELOG[0]
│  · 任务准点/考试倒计时提醒        │
│  ▸ 查看全部历史（展开 v1.0~v1.3） │
└─────────────────────────────────┘
```

## 四、数据与文件

| 文件 | 职责 |
|---|---|
| `src/app/changelog.ts`（新） | `CHANGELOG: { version, date, title, items[] }[]` 静态常量，最新在前；**发版约定：在数组顶部插入一条** |
| `src/app/daily-summary.tsx`（新） | 弹窗组件；纯函数 `daysBetween(a,b)` / `daysLabel(n)` / `greeting(date)` 导出可测 |
| `src/app/home.tsx`（改） | 挂载 `<DailySummary />`（ReminderBanner 旁） |
| `tests/daily-summary.test.tsx`（新） | 组件测试（mock `@/lib/db`，模式同 reminder-banner.test.tsx） |
| `README.md`（改） | 更新日志补 v1.4 条目 |

数据来源（全部复用现有 hooks，不动后端）：
- `useTasks()` + `todayTasks(tasks, today)`（overview/api）：今日未完成任务列表
- 完成数：`tasks.filter(t => t.dueDate === today && t.status === 'done')`
- `useExamsSoon()`（study/api）：未来考试已按日期排序，取前 3

## 五、纯函数定义

```ts
/** 两个 YYYY-MM-DD 的整天数差（UTC 纯字符串运算，避免本地时区） */
daysBetween(a: string, b: string): number
daysLabel(n: number): string      // n<=0 '今天' | n===1 '明天' | `n 天后`
greeting(date: Date): string      // <12 早上好 | <18 下午好 | 晚上好
```

## 六、测试用例

1. 有今日任务 + 考试 → 弹窗显示进度「已完成 1/2」、未完成列表、考试「3 天后」、v1.4 更新日志
2. 勾选未完成任务 → `repository.updateTask(id, { status: 'done' })` 被调用
3. 今日无任务且无考试 → 不弹窗（queryByText 为 null）
4. sessionStorage 已标记 → 不弹窗
