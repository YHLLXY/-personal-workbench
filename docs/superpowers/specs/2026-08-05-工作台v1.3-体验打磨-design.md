## 一、背景与目标

v1.2 完成个人中心、数据安全、总览聚合后，工作台功能已完整。v1.3 聚焦**操作效率与上手体验**（v1.2 spec 第九节列出的候选）：

1. **命令面板扩展**——当前 ⌘K 面板只有 3 个动作 + 页面导航，无分组、无快捷键提示、缺常用操作命令
2. **主题「跟随系统」三态**——当前 light/dark 二态，无法跟随设备
3. **全局快捷键**——除 ⌘K 外没有任何快捷键
4. **快捷键说明**——用户无从得知有哪些快捷键
5. **onboarding 首次引导**——新用户零引导

**用户已确认**：4 个功能全做；面板新增命令 = 切换主题 / 打开设置 / 导出备份 / 快捷键说明；新增快捷键 = ⌘N 新建任务 / ⌘⇧N 新建速记 / ⌘⇧X 全部打卡 / ⌘, 打开设置（Windows 下 ⌘ 显示为 Ctrl）。其余细节由实现方按本 spec 定案。

## 二、命令面板扩展

### 2.1 分组结构

`src/app/command-palette.tsx` 重写为**三组命令**（单文件命令表方案，不引入注册制——当前只有全局命令，注册制过度设计）：

```
新建（图标前缀 + 右侧快捷键 kbd）
  ├─ 新建任务      ⌘N      → 打开快速捕获（任务 Tab）
  ├─ 新建速记      ⌘⇧N     → 打开快速捕获（速记 Tab）
  └─ 打卡今日习惯  ⌘⇧X     → 打开快速捕获（打卡 Tab）
操作
  ├─ 切换主题（当前：深色）→ 主题三态循环（label 动态显示当前模式）
  ├─ 导出备份              → 触发下载 JSON 备份
  ├─ 打开设置      ⌘,      → 跳转 /settings
  └─ 快捷键说明            → 打开快捷键说明对话框
导航
  └─ 前往各页面（从 registry 的 allSubModules 动态生成，图标用子模块图标）
```

### 2.2 类型与数据

```ts
interface PaletteCommand {
  id: string
  label: string            // 静态文本；「切换主题」用函数生成动态 label
  icon: LucideIcon
  shortcut?: Hotkey        // 对应 src/lib/hotkeys.ts 中的条目，用于右侧 kbd 显示
  run: () => void
}
interface PaletteGroup { title: string; commands: PaletteCommand[] }
```

- 导航组由 `allSubModules` 生成（保持现有 `id: 'go:' + s.id`、`前往 {name}` 格式）
- 过滤逻辑保持现状：`q` 匹配 label 与导航 path（`includes`，不区分大小写不需要——现状为大小写敏感，保持）
- 空结果保留「没有匹配结果」提示
- **⌘K 监听从本文件移除**（迁移至全局快捷键，见第四节）；Esc 关闭保留

## 三、主题三态

### 3.1 状态模型（src/app/theme.tsx 重写）

```ts
type Theme = 'light' | 'dark' | 'system'        // 用户选择（持久化）
type ResolvedTheme = 'light' | 'dark'           // 实际生效
// Context 提供 { theme, resolvedTheme, toggle, setTheme }
```

- localStorage `wb-theme` 存三态值；**默认 'light'**（不改变现有用户行为）
- `resolvedTheme` 解析：`theme === 'system'` 且 `window.matchMedia` 可用时用 `matchMedia('(prefers-color-scheme: dark)')`，不可用（测试环境/旧浏览器）回退 'light'；否则等于 theme
- `document.documentElement.classList.toggle('dark', resolvedTheme === 'dark')`
- `toggle()` 循环：light → dark → system → light
- matchMedia change 事件监听：始终挂载，system 模式下跟随系统切换即时生效

### 3.2 顶栏按钮（src/app/layout.tsx）

- 图标按**当前生效主题**显示：`resolvedTheme === 'dark'` → Sun（点击将切到浅色），`theme === 'system'` → Monitor（跟随系统图标），否则 Moon
- `aria-label` 动态：`切换主题（当前：浅色/深色/跟随系统）`
- 点击调用 `toggle()`

## 四、全局快捷键系统

### 4.1 快捷键表（src/lib/hotkeys.ts 新建，纯函数可测）

```ts
export interface Hotkey {
  id: string
  key: string        // 单字符，比较时统一 toLowerCase
  mod: boolean       // Mac = ⌘(metaKey)，Windows = Ctrl(ctrlKey)
  shift: boolean
  description: string
}

export const HOTKEYS: Hotkey[] = [
  { id: 'palette',  key: 'k', mod: true, shift: false, description: '打开命令面板' },
  { id: 'new-task', key: 'n', mod: true, shift: false, description: '新建任务' },
  { id: 'new-note', key: 'n', mod: true, shift: true,  description: '新建速记' },
  { id: 'checkin',  key: 'x', mod: true, shift: true,  description: '今日全部打卡' },
  { id: 'settings', key: ',', mod: true, shift: false, description: '打开设置' },
]

export function isMacPlatform(): boolean
// navigator.platform 含 'Mac'

export function matchHotkey(e: { metaKey: boolean; ctrlKey: boolean; shiftKey: boolean; key: string }, isMac = isMacPlatform()): Hotkey | null
// mod 键：isMac ? e.metaKey : e.ctrlKey；e.key.toLowerCase() === hk.key
// shift 严格匹配 e.shiftKey === hk.shift；无匹配返回 null

export function formatShortcut(hk: Hotkey, isMac = isMacPlatform()): string
// Mac: '⌘⇧N'（修饰符按 ⌘ ⇧ 顺序，无 shift 则省略）；Windows: 'Ctrl+Shift+N'
// ',' 键直接显示（'⌘,' / 'Ctrl+,'）
```

### 4.2 全局监听（src/app/hotkeys.tsx 新建）

```tsx
export function useGlobalHotkeys()  // layout.tsx 调用一次
```

- 单例 window keydown 监听，`matchHotkey(e)` 命中后 `e.preventDefault()` 并分发：
  - `palette` → `setPaletteOpen(v => !v)`
  - `new-task` → `setCaptureTab('task'); setCaptureOpen(true)`
  - `new-note` → `setCaptureTab('note'); setCaptureOpen(true)`
  - `checkin` → `setCaptureTab('habit'); setCaptureOpen(true)`
  - `settings` → `navigate('/settings')`
- **必须 preventDefault**：Ctrl+N 会开新窗口、Ctrl+Shift+N 会开隐身窗口、⌘, 会开浏览器设置
- `src/app/command-palette.tsx` 移除自身 ⌘K 监听（避免双触发）

### 4.3 store 扩展（src/app/store.ts）

```ts
captureTab: 'task' | 'note' | 'habit'      // 快速捕获当前 Tab（store 驱动，避免跨开关残留——v1.2 踩坑 #12）
setCaptureTab: (t) => void
shortcutsOpen: boolean                     // 快捷键说明对话框
setShortcutsOpen: (v) => void
```

- `src/app/quick-capture.tsx`：删除本地 `useState(tab)`，改为读 store `captureTab`，Tab 按钮写 `setCaptureTab`（store 化后每次打开行为由入口显式设定：面板三个命令设对应 Tab，FAB 设 task）

## 五、快捷键说明对话框（src/app/shortcuts-dialog.tsx 新建）

- 用现有 `@/components/ui/dialog`（base-ui 包装），与 ChangePasswordDialog 同模式
- `open` 由 store `shortcutsOpen` 控制（`onOpenChange={setShortcutsOpen}`）
- 内容：`HOTKEYS.map` 渲染 每行 = description（左）+ `<kbd>{formatShortcut(hk)}</kbd>`（右），标题「快捷键」
- Esc 关闭（base-ui Dialog 默认 dismissible）
- 入口：命令面板「快捷键说明」命令（`setShortcutsOpen(true)`）
