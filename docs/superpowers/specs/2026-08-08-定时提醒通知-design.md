# 定时提醒通知 设计文档（方案 C：全量版）

> 状态：待用户批准（2026-08-08 展示，批准后进入 writing-plans → 子代理执行）
> 范围：个人工作台（React 19 + Vite + TS + Tailwind v4 + shadcn/ui + Supabase + Vercel）

## 一、需求

1. 今日待办：任务在设定的时间向手机发送通知
2. 学习管理：考试在考前 3 天 / 1 天 / 1 小时发送通知
3. 全平台（手机/电脑），应用关闭也要能收到（系统推送）
4. 国内网络环境可用（不依赖 FCM）

## 二、调研结论（2026-08-08）

| 通道 | 结论 |
|---|---|
| 安卓 Chrome Web Push（FCM） | ❌ 国内被墙，官方确认不可用（需代理+GMS） |
| **iOS Safari 16.4+ Web Push（APNs）** | ✅ 国内可用，无需开发者账号，需「添加到主屏幕」 |
| Server酱（微信） | ✅ 安卓备选通道，填 SendKey 即用 |
| 应用内提醒（横幅/列表/角标） | ✅ 基础层，全平台，零依赖 |
| Vercel Cron | ❌ Hobby 每天仅 2 次 |
| **Supabase pg_cron + pg_net** | ✅ 免费版无次数限制（分钟级），pg_net 可 POST 触发 Vercel 函数 |

## 三、架构

三层提醒（全部实现）：
- **应用内提醒**（打开即见）：首页横幅 + 提醒中心页 + 导航角标
- **前台系统通知**（打开+前台）：Notification API 弹窗
- **后台系统推送**（应用关闭也收）：Web Push（APNs/桌面）+ Server酱（微信备选）

数据流：
```
pg_cron (每10分钟) → pg_net → POST /api/cron-notify (Bearer CRON_SECRET)
前端打开应用 → GET /api/check-reminders (登录态)   ← 兜底，双保险
        ↓
/api/reminders.ts（单文件）→ 提醒生成引擎（纯函数）
        → 幂等写 wb_reminders
        → 到期提醒 → Web Push（web-push 库，npm 包可 import）
                    → Server酱（若配置）
        → 标记 sent_at
```

## 四、数据模型（003_reminders.sql，全部向后兼容）

```sql
alter table wb_tasks add column if not exists due_time text;      -- HH:mm 可选
alter table wb_exams add column if not exists exam_time text;     -- HH:mm 可选（考前1小时必需）

create table wb_reminders (
  id text primary key,
  user_id uuid not null default auth.uid(),
  ref_type text not null check (ref_type in ('task','exam')),
  ref_id text not null,
  kind text not null check (kind in ('due','exam-3d','exam-1d','exam-1h')),
  scheduled_at timestamptz not null,        -- 计划提醒时间
  sent_at timestamptz,                      -- 已发送时间（null=未发送）
  dismissed_at timestamptz,                 -- 用户已忽略
  created_at timestamptz not null default now(),
  unique (user_id, ref_type, ref_id, kind)  -- 幂等去重
);
create table wb_push_subscriptions (
  id text primary key,
  user_id uuid not null default auth.uid(),
  endpoint text not null,
  keys_p256dh text not null,
  keys_auth text not null,
  user_agent text,
  created_at timestamptz not null default now()
);
create table wb_channel_configs (
  user_id uuid primary key default auth.uid(),
  serverchan_key text,
  updated_at timestamptz not null default now()
);
```

## 五、提醒生成引擎（src/lib/reminders.ts，纯函数可测试）

- `computeReminders(tasks, exams, now: Date)` → 应到期的提醒列表
  - 任务：`dueDate + dueTime` 到点（无 dueTime 则不生成准点提醒，仅任务页展示）
  - 考试节点：`examDate - 3d`（08:00）、`examDate - 1d`（08:00）、`examDate + examTime - 1h`（需 examTime）
- `diffReminders(existing, computed)` → 新增/过期差异（幂等）
- 时区：now 按 Asia/Shanghai 换算后计算（pg_cron 为 UTC，函数内 `+8h`）
- 边界：考试已过、任务已完成 → 不生成；同日重复运行 → 不重复生成

## 六、Vercel 函数（api/reminders.ts，单文件铁律！）

- **单文件**（沿用 api/hot.ts 教训：Vercel 函数环境不支持跨文件相对导入；web-push 为 npm 包正常 import）
- 两个入口同一实现：
  - `POST /api/cron-notify`：校验 `Authorization: Bearer CRON_SECRET`（env）
  - `GET /api/check-reminders`：校验 Supabase JWT（登录态）
- 流程：读 tasks/exams/reminders/subscriptions/configs → 生成 → 插入 → 到期未发 → 发送（web-push 410 过期订阅删除；Server酱失败静默记录）→ 标记 sent_at
- 幂等：重复触发不重复发送（sent_at 判断 + unique 约束）
