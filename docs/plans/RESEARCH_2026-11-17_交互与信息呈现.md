# 调研：交互反馈、动效与信息呈现（2026-11-17）

> 触发的三个具体问题：① 提醒点「完成」后卡片不消失；② 项目页「刷新」没有任何反馈；③ 项目详情正文全是文字、可读性差。
> 合并成一条主线：**用户做了动作，界面必须立刻给出可感知的结果**。

## 1. 成熟产品怎么做

| 产品 | 可借鉴的点 |
|---|---|
| **Things 3** | 勾选完成的瞬间就用「淡出 + 行内收拢」把任务移走（不是等接口回来再重排）；所有状态变化都有形变，没有硬切 |
| **Todoist** | 完成是乐观的：先本地移入「已完成」，失败才回滚并 toast；撤销入口就在 toast 上 |
| **Linear** | 列表项的状态变更用 150–200ms 的位移+透明度过渡；加载用骨架而不是 spinner |
| **Notion** | 长文正文有稳定的排版节奏（行宽 ~68ch、h2 带分隔、表格可横向滚动）；折叠区块默认状态按「有没有内容」决定 |

共同点：**乐观更新 + 形变过渡 + 明确的结果反馈**；没有一个是「等服务器返回再动」。

## 2. 我们现在的动效资产

| 已有 | 位置 | 评价 |
|---|---|---|
| 页面进入 `rise-in` 300ms | `index.css` `.page-enter` | 可用，但路由切换时旧页面直接消失，没有「同时」的感觉 |
| 卡片 stagger `card-enter` | `index.css` | 可用 |
| 勾选弹跳 `check-pop` | `index.css` | 可用 |
| 列表 FLIP | 任务列表 | 已有，保持 |
| `prefers-reduced-motion` | 三处 | ✅ 已覆盖，新增动效必须继续遵守 |

缺少的：**按钮按压反馈**、**浮层进入/退出的位移**（快速捕获是直接出现/消失）、**骨架 → 内容的淡入**（现在是硬切）、**操作结果的就地反馈**（刷新无 toast、完成无退场）。

## 3. View Transitions API（要不要上）

- 同文档转场：Chrome 111+ / Safari 18+ / Firefox 144+（2025-10 起）——覆盖率够。
- 它能做「旧页面淡出 + 新页面淡入」的**真正共享元素**转场，但需要把路由更新包进 `document.startViewTransition()`；
  React Router 7 没有官方集成，需要自己包一层，且要处理 Suspense 边界的先后。
- **结论：这一轮不做路由级 View Transition**（风险/收益不划算），只做「冒烟级」增强：
  按钮 `active:` 反馈、浮层 `transform` 进出、列表项退出过渡、骨架淡出。若后续仍想升级，再单独评估。

## 4. 项目详情页排版（图四）

**根因（已定位到代码）**：`api/projects.ts` 的 `fetchDetail` 把**含 YAML frontmatter 的整篇 md** 丢给 GitHub Markdown API，
于是 `---` 与缩进的 YAML 被渲染成一堆列表项，出现在正文最上方（截图里那一片 `date:/tags:/project:`）。

**修法**：渲染前剥掉 frontmatter（`^---\r?\n[\s\S]*?\r?\n---\r?\n`），头部信息本来就已经由列表接口填好（emoji/phase/stack/aliases）。

**排版改造清单**（纯 CSS，不引库）：
- 正文容器限宽 `~68ch`，行高 1.8；
- `h1` 不重复（页面已有大标题），正文 h1 降级或隐藏；
- `h2` 加左侧色条 / 上间距，形成章节节奏；
- 表格外层允许横向滚动（`overflow-x:auto` 包裹，避免撑破页面——v1.33 刚踩过 truncate 少 `min-w-0` 的坑）；
- 引用块、代码块、图片加统一间距与圆角；
- 长文档加「回到顶部」或目录（可选，第二阶段）。

## 5. 复盘页（图五）

- 折叠区默认态：现在「成就/反思/感恩/收获」默认关闭，「总结/明日计划」默认展开（`FormSection defaultOpen`）。
  问题：**编辑已有复盘时字段是收起的**，用户看不到自己写过什么；新建时又一口气展开两个大框。
  **改法**：默认态由「该字段有没有内容」决定 —— 有内容展开、空白收起；用户手动展开/收起后按日期记住（localStorage）。
- 明日待办：现在点「生成」只弹一个 toast，生成的条目是**明天到期**，在「今日待办」里根本看不见 → 用户以为没生效。
  **改法**：生成前给出可编辑预览（解析结果逐条勾选）+ 生成后回显「已生成 N 条」并给「查看」入口；对「同标题+同日期」的存量任务去重。
